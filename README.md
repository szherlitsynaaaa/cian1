# cian1 · Пустой репозиторий

Приватный учебный репозиторий для практики «Три репозитория». Здесь намеренно нет кода, дизайн-системы и правил: агент собирает прототип с нуля. Так видно, что даёт модель сама по себе. Сравниваем с `cian2` — стек и UI-kit Циана — и `cian3` — полное рабочее место дизайнера.

- [tasks/](tasks/README.md) — карточки задач практики.
- [team/](team/README.md) — участники: у каждого свой файл `team/<github-логин>.md`.

Свою работу ведите в ветке `<github-логин>/<задача>` и показывайте пул-реквестом.

## Локальный запуск прототипа аукциона

```bash
pnpm install
pnpm dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Для
проверки production-сборки используйте `pnpm build`.
