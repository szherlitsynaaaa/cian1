# Аукцион квартиры · Циан

Статус: готово. Финальная версия — вертикальный промо-ролик в стилистике Циана, без озвучки и музыки.

## Бриф и решения

- Длительность: 15 секунд; формат: 9:16, 1080×1920, 30 fps.
- Назначение: промо реального прототипа аукциона квартиры.
- Сюжет: фирменное вступление с архитектурной графикой → продавец задаёт условия → проверяет и публикует лот → покупатель открывает карточку → делает ставку → получает статус «Ставка принята».
- По присланному бренд-референсу каждый экран расположен в белой карточке на синем фирменном фоне; оранжевый и жёлтый слои образуют объёмную подложку. Переходы — карточка входит справа, а предыдущая уходит влево с масштабом и наклоном.
- Источник экранов и текстов: src/App.tsx, src/styles.css, SCREEN_MAP.md.
- Бренд-токены взяты из src/styles.css; актуальный SVG-логотип взят из компонента CianLogo в src/App.tsx. В профиле ролика используется локальный Manrope из шаблона скилла, поскольку исходный Lato подключается к прототипу по CDN.
- Нет озвучки, субтитров, музыки и придуманной функциональности.

## Результаты

- out/auction-promo-cian-layers_9x16.mp4 — финальный MP4, без аудио.
- out/auction-promo-cian-layers_9x16_sheet.jpg — контрольный лист финального видео.
